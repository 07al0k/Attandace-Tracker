# Attandace-Tracker

This is a simple C# console application that allows you to track employee attendance.

**Features:**
- Mark employees as present or absent.
- Display a summary of attendance.
- Console-based interface.
- Uses object-oriented programming with classes.

**How to Run:**
1. Make sure you have the .NET SDK installed.
2. Clone this repository or download the source code.
3. Open a terminal in the project directory.
4. Run the application using the command:
   ```
   dotnet run
   ```

**Example Output:**
```
=== Attendance Tracker ===
Is Alice present? (y/n): y
Is Bob present? (y/n): n

--- Attendance Summary ---
Alice (ID: 101) - Present
Bob (ID: 102) - Absent
```
